鸣潮商城系统

以上市游戏为背景 · 8种货币 id 唯一 & 术语统一 · 商品/界面/购买流程规则闭环

下载原始文件 xlsx
项目概况： 以上市游戏《鸣潮》为背景的商业化模块配表作业。以「可读配表」形式交付，覆盖商城系统的核心商业化结构：8 张货币配置（id 唯一、统一术语）、两级商品分类、面板界面说明以及购买/显示条件，把「货币 → 商品 → 界面 → 购买流程」串成可推演的闭环。
核心亮点： ① 货币 id 全局唯一且版本可追溯（精修中修复了贝币 id 冲突 1006→1008）；② 命名术语统一（如「残振珊瑚」「余波珊瑚」等不作混用）；③ 规则闭环可推演——每种货币有明确来源（充值/抽卡/深塔/全息战略等），每个商品有明确的显示与购买条件。

二、功能概述

设计目的：商城系统是游戏内嵌的核心商业化与资源分发平台，为玩家提供虚拟商品购买，同时支撑游戏多样的运营活动与营收目标。

功能概述：

  1. 玩家可以浏览并购买想要的商品
  2. 对皮肤类商品进行预览
  3. 玩家可以按商品分类浏览商品
  4. 可进行配表

功能定位清晰：浏览 / 预览 / 分类 + 可配表，是一个「运营可配置」的商城底座，而非写死的静态页面。

三、功能说明

3.1 功能开启

  1. 在初次进入游戏时自动开启
  2. 按下 esc 唤出终端（即菜单）后点击商城即可打开

3.2 功能退出

点击右上角两个退出键可直接退到游戏主界面或者上一级页面。

3.3 商品分类

商品总共分为两级分类：

一级分类： 特别推荐、礼包中心、装扮橱窗、海市兑换、凝刻月相、积分商店

二级分类按不同一级分类划分如下：

一级分类二级分类
特别推荐热卖皮肤、月相观测卡（月卡）
礼包中心特惠专区、常驻礼包、等级礼包
装扮橱窗服饰橱窗、换影橱窗
海市兑换余波珊瑚、残振珊瑚、聆听星声
凝刻月相（无二级分类）
积分商店深塔兑换所、演练商店、试炼商店

3.4 商品显示条件和开启条件

显示条件：所有商品均在进入游戏后可显示。
购买条件：某些商品存在购买条件，未满足时无法购买。

存在的购买条件如下：
· 没有超过能拥有的上限
· 等级达标
· 拥有角色本体

「显示一律可见、购买按条件拦截」的规则设计，让商城既能全量曝光商品做运营，又能在购买侧做硬性校验，是商业化里「视觉全开放 + 购买受控」的常见做法。

四、界面说明

4.1 一级分类区

  1. 点开商城即进入特别推荐页面
  2. 按照相应的顺序进行分类排列
  3. 点击可切换对应的商城分类

4.2 二级分类区

  1. 存在二级分类的页面会显示二级分类
  2. 若不存在二级分类（如凝刻月相界面）则不显示二级分类，直接显示商品

默认落地页固定为「特别推荐」，且支持按二级分类进一步细化；无二级分类的模块（如凝刻月相）则降级为直接展示商品，做到界面层级与数据层级一一对应。

五、货币配置表

核心数据表，定义了商城全部货币。货币类型分四档：（1）高级货币、（2）兑换代币、（3）特殊代币、（4）通用货币，并为每种货币标注了来源路径。

货币体系规则可推演： 「月相」（充值得唯）与「星声」为可充值的 高级货币；「余波珊瑚 / 残振珊瑚」是抽卡溢出的兑换代币，可导向「海市兑换」商店；「深境记录、演练数据集、试炼纹币」分别对应深塔与全息战略玩法产出的特殊代币，与「积分商店」下的兑换所 / 演练商店 / 试炼商店一一对应；「贝币」为全游戏通用的日常货币。每个货币 id 全局唯一、术语统一（精修期将原冲突的 1006 更正为 1008「贝币」）。
