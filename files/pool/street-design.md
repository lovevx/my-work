# 街道 v3：四道谜题与一次返程验证

依据：[俯视角解谜设计思路拆解](puzzle-design-method.md)与本次确认方案。使用当前工程的怒规则；参考文档中的恐惧退避、听觉感知、破墙只是其他方案的例子，没有引入本关。

## 打开与操作

- 可编辑场景：`Pool/Assets/AngerStreet/Scenes/AngerStreetV3.unity`。
- Windows 试玩：`D:/聚光灯gj/deliverables/AngerStreetV3/AngerStreet.exe`，保留同目录数据文件。
- WASD 移动与角色转身；Shift 奔跑；E 拾取、旋转接头、拉柄、切换供电、中心交付；Space 怒冲锋；1–4 装备；Tab 快览；Esc 暂停详情；R 完整重开。三次实验失败后，H 查看或收起可选提示。
- 首次体验目标为 10–15 分钟，尚须未读文档玩家验证。地图总览默认关闭；任务栏描述障碍与结果，不提供逐步解法。

## 稳定规则

玩家基础步速 5、奔跑系数 1.6，怒区常驻加速 ×1.5，得到步行 7.5、奔跑 12。怒光球首次拾取自动装备，在怒区按 Space 沿角色显示的四向朝向冲锋，速度 16、冷却 4 秒，持续到实体障碍撞停、眩晕 0.65 秒。鼠标不改变冲锋方向。

一个共享怪物持续追击玩家；怒区速度为基础 4 ×2，起冲锁向，真实碰墙后重新选择追击方向。导航寻找可达追击点，没有巡逻、听觉、破墙、蓄力或人为固定轴往返。怪物和玩家分别查询自己的位置。中心没有怒加速，也没有无敌、安全或怪物禁入规则。

本场景没有哀光球、哀区、透视、穿墙追击或黑暗服务间。

## 布局与流程

```text
西侧民居：线路板 ─窄口─ 主街 ── 中心交付
      │                  │             ↑
   供电卷帘          窄口外检修柄       归途通道
      │                  │             ↑
维修铺：压板→直线→远端保持柄            归途卷帘
      │     └错误转角     │             ↑
    餐馆 ───窄口──── 主街 ─窄口─ 商店前厅配电盘
                                      │
                                    后屋卷帘
                                      │
                                    街道钥匙
```

主街净宽 4，观察窄口净宽 1；玩家碰撞体宽 0.4，怪物直径 1.1。实际墙体排除怪物进入窄口，没有隐藏安全区。维修铺所有其他入口同样依赖第一道题的供电，不能从餐馆或主街绕过线路板。

站在压板附近时，镜头自动拉远并向通道前方取景，能同时看见错误转角、远端保持柄和撞停墙，再决定是否冲锋。离开准备位置后恢复跟随视角。怪物初始位于主街远端，为初次进入观察窄口保留接近距离；仍从开局持续追击。

民居在上段，维修铺在中段，餐馆提供下段横穿前的观察位置；东侧商店前厅能切换后屋和归途供电。返程通道净宽 3，怪物也能通过。配电盘位于两道供电门之外，钥匙房内部没有必须操作的换档装置，因此取物后可以回前厅调整。

## 四张谜题设计卡

| 字段 | ① 接通维修铺 |
|---|---|
| 目标 | 打开看得见的维修铺卷帘 |
| 已知规则 | 相接的端口传递电流；转动 L 形接头改变两端方向 |
| 证据 | 电源、固定线段、两只接头、门侧线路；通电段为暖黄色，断开的段为灰色 |
| 阻碍 | 上游和下游均未相接，直接拉门无效 |
| 核心推理 | 先将电源接向上游，再把电流转向维修铺线路 |
| 实验 | 接头可按 E 反复旋转，无资源消耗 |
| 失败反馈 | 电流停在第一个断点，另一段不会假亮 |
| 成功状态 | 两接口连接后，机械保持锁定供电；维修铺全部入口开启 |
| 迁移 | 之后配电仍遵循“线路决定受电设施” |

| 字段 | ② 离岗的追击者 |
|---|---|
| 目标 | 手动拉开主街检修柄 |
| 已知规则 | 怪物追击玩家，起冲锁向，碰墙才重新选向 |
| 证据 | 窄口观察位置、两端撞痕、持续脚步与墙体撞击声 |
| 阻碍 | 检修柄在窄口外，玩家在遮挡后距离不足以操作 |
| 核心推理 | 用站位影响下一次追击方向，利用已锁定的远离路线离开窄口 |
| 实验 | 在窄口内观察、改变位置，再等待实际起冲与碰墙 |
| 失败反馈 | 可看见撞击、重新选向与捕获；开关不会因怪物经过自动完成 |
| 成功状态 | E 拉柄后检修供电持续保留，压板获得电源 |
| 迁移 | 餐馆横穿、后屋取物与返程仍利用同一追击规则 |

| 字段 | ③ 直线与停点 |
|---|---|
| 目标 | 到达远端保持柄，永久开启卷帘 |
| 已知规则 | 怒冲锋速度高、锁定四向、撞墙眩晕；压板释放后卷帘延时关闭 |
| 证据 | 可观察的直线、较近的错误转角、终端墙、倒计时灯与远端保持柄 |
| 阻碍 | 怒区奔跑仍无法在关闭前穿过真实门体，错误转角会提前撞停 |
| 核心推理 | 先选连续直线和安全终点，再释放冲锋；到达后等待恢复并拉柄 |
| 实验 | 压板可反复触发，错误路线可步行返回 |
| 失败反馈 | 门关闭、灯灭、撞墙眩晕；累计三次失败提供可选 H 提示 |
| 成功状态 | 保持柄永久开门，后屋配电盘获得供电 |
| 迁移 | 返程冲锋同样须考虑方向与撞停后的位置 |

通道约 13.4 单位的实际完整通行距离，延时初值 0.9 秒。卷帘关闭遇到角色占据门体时等待其离开，防止夹入实体。成功抵达远端不会被误计为操作失败。

| 字段 | ④ 取物与归途 |
|---|---|
| 目标 | 获取街道钥匙，并选择回中心的通路 |
| 已知规则 | 一个电源同时只维持一个输出；改变供电会改变实体通路 |
| 证据 | 公共前厅配电盘、连向后屋和归途的两条线、先前看见的断电归途线 |
| 阻碍 | 后屋与归途不能同时供电；拾取钥匙不自动切换供电或完成交付 |
| 核心推理 | 去程供电后屋，带钥匙回前厅，再把供电转向归途 |
| 实验 | 配电盘可反复切换，门和线路立即反馈状态 |
| 失败反馈 | 未完成检修时显示缺电；断电门维持实体阻挡 |
| 成功状态 | 新归途对双方开放，需要再次判断怪物位置；中心 E 交付记录 1/5 |
| 迁移 | 用先前学到的线路关系和怪物锁向规则处理新的路线 |

原主街路线依然可作替代策略，不用隐藏条件强制玩家走归途。解锁的新路线改变了双方机会，是否更适合撤离取决于怪物当前位置。

## 编辑、状态与验证

地面、墙体与家具保留可编辑瓦片地图（Tilemap）。机关为独立对象；`StreetCircuitControl` 处理可反复操作的场景控制，`StreetTimedShutter` 处理压板、倒计时与防夹，`StreetV3Puzzle` 持有本地持续进度与 1/5 交付。原背包、玩家融合及共享追击代码没有为 v3 改写。

被捕沿用背包演示规则，回出生点并保留光球、任务物、线路完成、检修供电、永久开门、供电档位和交付。临时压板倒计时复位。R 重新加载场景，清空全部本关进度。

菜单 `Pool > Anger street > Build four puzzles v3` 重建 v3，会覆盖已生成的 v3 场景；手工编辑后不要直接运行。`Build playable v3` 用保存的 v3 场景构建，不改工程构建场景列表。v2 保留。

功能与物理检查：`-street-v3-check -street-output C:/Temp/PoolStreetV3QA`。路线检查：`-street-v3-live-check -street-output C:/Temp/PoolStreetV3LiveQA`。功能检查可以隔离怪物验证机关，再启用怪物检查实际锁向、碰墙、窄口和捕获保留；路线检查从真实初始位置出发，全程启用怪物，不瞬移、不延长保护、不使用捕获回城完成。

结果保存于 `Pool/Captures/AngerStreetV3/`。检查截图来自游戏摄像机渲染，不包含屏幕叠加背包界面。行为记录含开关操作、怪物碰墙、实验失败与交付事件。

### 玩家测试门槛

请三名未读文档玩家试玩，至少两人能在 15 分钟内交付，并解释怪物锁向、冲锋路线与供电切换。分别记录未注意线索、预测错误、操作失败、偶然成功。已知路线的自动通关不能替代这项验证。

可直接使用同目录 [玩家测试记录表](player-test-sheet.md)。

实施验证结果见同目录 `verification.md`。
