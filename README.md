# 李伟翔 · 游戏策划作品集（GitHub Pages）

游戏系统 / 数值策划 —— 求职线上作品集，7 件精修作品，均可在网页端在线阅读，或下载原始 docx / xlsx。

## 在线访问

仓库启用 GitHub Pages 后，首页即为作品集总目录。结构如下：

```
portfolio-site/
├── index.html                 # 作品集总目录（首页）
├── assets/site.css            # 全站共享设计系统
├── works/
│   ├── tan-dong-xian-feng.html    # 探洞先锋 · GDD（主策划，从0到1）
│   ├── boomame.html               # Boomame · 独立 Godot 项目
│   ├── kongzhigui-1st.html        # 空之轨迹1st · 战斗与养成拆解
│   ├── mingchao-mall.html         # 鸣潮商城 · 商业化配表
│   ├── wangzhe-numerics.html      # 王者数值建模 · 作品摘要
│   ├── zhangjian-chuanshuo.html   # 杖剑传说 · 体验分析
│   └── chaoziran-tutorial.html    # 超自然行动组 · 新手引导改造
└── files/                     # 原始精修文件（docx / xlsx）下载
```

## 部署方式

1. 将本目录内容推送到 GitHub 仓库（建议仓库名 `portfolio` 或 `game-designer-portfolio`，设 Public）。
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch` → 分支 `main`，目录 `/ (root)`。
3. 保存后等待 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。
